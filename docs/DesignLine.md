# Version 0.0.1

BeChat 只提供基础的单独的抽象的接口，比如登录、注册、消息...，主要的操作逻辑由客户端自己设计。

## 基础架构
1. 用户注册信息存储在内存中（以后可能会持久化）
2. 只有一个聊天室（以后可能支持多聊天室或者私聊）
3. 聊天室历史数据存储在内存中（以后可能会持久化）


## 基础功能
1. 用户注册
2. 用户登录
3. 数据获取
   1. 获取历史聊天消息
   2. 获取在线用户数据
4. 消息推送
   1. 其他用户新消息推送
   2. 用户加入聊天室推送



## 协议设计

使用 TCP 进行数据传输，且使用 TLS/SSL 进行数据加密。

```
TLV {
  Tag:      2 bytes,
  Length:   2 bytes,
  Value:    <Length> bytes
};
```
