# BeChat

使用 C++ 编写的聊天服务器。


1. 使用 Asio 库（non-boost）为基本框架
2. 使用自定义 TLV 协议
3. 用户数据以及聊天数据存储在内存中
4. 暂不引入数据库或其他组件
5. 暂不考虑数据持久化问题

BeChat 只提供基础的单独的抽象的接口，比如登录、注册、消息...，主要的操作逻辑由客户端自己设计。

BeChat 在内存中保存用户注册信息、在线用户信息、群聊历史消息等；私聊消息不保存。
客户端通过独立的 UDP 通道发送心跳，BeChat 超过 30 秒未收到心跳即判定用户断开连接。
每个 TCP Session 只执行一次命令就断开（类似 HTTP 协议）；用户是否在线纯粹由 UDP 心跳判断，协议保留未来长连接的可能性。
