# 协议格式

协议固定为 TLV 报文，由三个字段 [tag, length, value] 组成且全双工通信。

Tag 字段固定为 16 bit 即 2 bytes。
Length 字段固定为 16 bit 即 2 bytes。
Value 字段的长度是可变的，由 Length 字段指定，故最大长度为 65536 bytes。

Tag 和 Length 在网络传输过程中使用大端序。

# 协议约定

Value 的格式为 JSON 字符串。

## Request ID

协议使用全双工通信，故客户端可在请求报文 Value 中使用 request_id 字段区分不同请求报文的响应报文。

该字段的值应当为 32 bit 无符号整数，服务端应当不对该值进行任何处理，
只检测该值是否为 32 bit 无符号整数，并且原样在响应报文中返回该字段。

当服务端接受到的请求报文中无 request_id 字段，应当在响应报文中设置 request_id 字段值为零。

# 协议字段

## 用户注册

> Tag: 0x0001

**请求报文**

| **字段**   | **值类型** | **用途**                     | **必需** |
| ---------- | ---------- | ---------------------------- | -------- |
| request_id | uint32     |                              | 否       |
| username   | 字符串     | 想要注册的用户名             | 是       |
| password   | 字符串     | 注册成功后该用户名的登录密码 | 是       |

**响应报文**

| **字段**    | **值类型** | **用途**   | **必需** |
| ----------- | ---------- | ---------- | -------- |
| request_id  | uint32     |            | 是       |
| status_code | uint32     | 响应状态码 | 是       |

## 用户登录

> Tag: 0x0002

**请求报文**

| **字段**   | **值类型** | **用途**           | **必需** |
| ---------- | ---------- | ------------------ | -------- |
| request_id | uint32     |                    | 否       |
| username   | 字符串     | 想要登录的用户名   | 是       |
| password   | 字符串     | 该用户名的登录密码 | 是       |

**响应报文**

| **字段**      | **值类型** | **用途**                   | **必需** |
| ------------- | ---------- | -------------------------- | -------- |
| request_id    | uint32     |                            | 是       |
| status_code   | uint32     | 响应状态码                 | 是       |
| access_token  | 字符串     | 用户执行操作所需的访问令牌 | 否       |
| refresh_token | 字符串     | 用于刷新用户的访问令牌     | 否       |

如果响应状态码表示请求未成功完成，则 access_token 和 refresh_token 字段将不会返回。

## 用户刷新访问令牌

> Tag: 0x0005

**请求报文**

| **字段**      | **值类型** | **用途**       | **必需** |
| ------------- | ---------- | -------------- | -------- |
| request_id    | uint32     |                | 否       |
| refresh_token | 字符串     | 用户的刷新令牌 | 是       |

**响应报文**

| **字段**     | **值类型** | **用途**           | **必需** |
| ------------ | ---------- | ------------------ | -------- |
| request_id   | uint32     |                    | 是       |
| status_code  | uint32     | 响应状态码         | 是       |
| access_token | 字符串     | 新的用户的访问令牌 | 否       |

如果响应状态码表示请求未成功完成，则 access_token 字段将不会返回。
